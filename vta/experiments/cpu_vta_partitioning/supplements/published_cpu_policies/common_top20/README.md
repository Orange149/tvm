# 双网络共同Top-20验证

五份既有/修订名单分别为当前模型、竞争约束语义修订、固定组分支、双分支选择和Tarnawski物理单核适配。所有名单各20项，逐项用相同输入、程序、窗口和当前boot共同测量。相同执行配置共享一次结果；方法标签不进入执行身份。

语义修订复用此前`weights_only`消融公式：非均匀线程份额及主机CPU容量保持，开放并发不再累计整组墙钟，实际同组串行仍累计完整服务。这里没有宣称发明了新的搜索算法或已经修复所有共享慢化。

固定组和双分支亦为既有实现；此次补齐两网络全20项的共同数据。固定组是明确的受限策略家族，原主模型和语义修订仍搜索原有全部合法域。混合选择改变候选覆盖，其评分误差与当前模型相同。

当前合并池ResNet18为78项，YOLO为80项。完整域与独立C++枚举、标量评分和程序身份已核验；重复配置不新增任务。旧性能不会用作本批结果。
