# 隔离逐线程份额：核时容量与资源占用的联合消融

此分支使用原775项隔离成本中已有的线程核时份额，没有读取流水FPS拟合系数。
既有小型固定切图的逐线程修正未改善选点；本轮检验的是完整切图、线程预算和主机位置联合选择，
并将“只改核时分布”和“分布＋资源包络”分开。

## 1．成本语义及公式

原始CPU阶段的计算核时为U[i]、交接核时为B[i]、线程数为n[i]，逻辑线程j映射到物理核心m[i,j]。

```text
均分：        w[i,j] = 1 / n[i]
已有隔离份额：w[i,j] = 整个标定会话中线程j的CPU时间增量 / 该阶段线程CPU时间增量之和

D[c] = sum(i,j 且 m[i,j]=c, U[i] × w[i,j]) + sum(i 且 caller[i]=c, B[i])
```

计算核时采用计入帧的进程时钟；份额来自包含预热、尾部及调用线程交接的整个隔离会话。
因此它是对计入窗口计算核时的近似分配，不是逐worker精确计算区间核时。
整数纳秒按原最大余数法分摊，核时总量守恒，交接仍只归调用线程一次。
三项极短两线程签名CPU12、CPU14、CPU17没有可分辨份额，显式保留均分回退；单线程份额恒为1。
其他同核数集合仍采用同构核置换假设；逻辑worker顺序与执行器一致。

两组完整域消融分别为：

1. 既有容量公式F，替换D的核时分布。
2. 替换D后，保留主机集中项及线程组占用项，取三者最大值。

包络定义及论文依据见[设计](DESIGN_zh.md)。固定组、核预算和计算／主机工作归属是成熟资源分配契约的适配；
开放重叠的线程组包络是本项目规划代理，不称为论文直接给出的真实延迟公式。

## 2．为什么要保留worker角色

CPU0–2三线程的已有份额为40.3%／35.4%／24.3%。均分会掩盖两个helper约20ms核时差。
同一计算配置下，均分评分对主机核心1／2分别为75.425／75.663ms，倾向核心1；
采用已有份额后分别为79.066／75.738ms，倾向核心2。

资源行为压缩随之保留有序`worker_core_map`。不同worker的负载不同，不能只保留caller、
允许集合及“主机落在某个helper”就宣称两种放置等价。物理核镜像仍可规范化，但必须保持逻辑worker角色对应。
低贡献阶段变体及未进入Top-2分层池的行为族仍可能丢失，不宣称全域最优行为覆盖。

## 3．完整域与冻结

原公式份额版和包络份额版分别通过九个上下文的独立C++枚举：4623条切图、966240306个增强分配组合。
搜索壁钟分别770.6秒和812.6秒；两次并发运行，不能将两数相加当作实际顺序等待时间或CPU用时。
没有扩大／缩小线程、核心集合、门控或VTA岛域，没有新增组件标定或修改运行库。

两套“原均分20项／新评分严格20项／新评分行为20项”都于2026-11-08 10:20:32 UTC冻结，
早于诊断最后资格验收10:21:19 UTC，因而早于诊断正式性能测量。
原公式份额版并集59项，包络份额版并集58项；先用六项诊断选择模型开发分支，未把两套都完整上板。

## 4．六项诊断结果

18会话、342次完整推理，两轮严格反向顺序。主机核心1／2／3的三项保持计算配置完全相同。

|配置|第一轮FPS|第二轮FPS|平均间隔换算FPS|
|---|---:|---:|---:|
|原均分静态第一名|11.563|11.747|11.654|
|均分包络第一名，主机核心1|10.324|10.887|10.598|
|逐线程份额原公式第一名|11.185|11.261|11.223|
|逐线程份额＋包络第一名|13.134|12.927|13.030|
|匹配放置，主机核心2|12.849|12.761|12.805|
|匹配放置，主机核心3|10.599|10.624|10.611|

仅改主机位置：核心1→2时，CPU0–2流水服务约93.7→77.8／78.5ms，第二CPU阶段仍约71–72ms。
改到核心3时，CPU0–2约74–75ms，第二CPU阶段变成约93ms。阶段慢化随主机工作的重叠位置转移。
这支持按具体核心负载建模；不能把所有helper当成一样，也不能将核心2规定为通用最优位置。

只改份额的原公式仍选择四线程＋三线程开放重叠，前段实际约88–90ms，选择质量没有改善。
联合版选择三线程＋单线程主计算组分离，主机落在负载较低的helper核心；另有轻CPU阶段复用核心。
这支持进一步验证两项修改的组合，不证明每项单独都有效，也未分离屏障、运行队列和缓存的因果占比。

模型分支选择属于方法开发：在两个事先定义的加权第一名中比较平均间隔，并核查两轮相对原第一名的方向。
选择规则不是诊断前预注册的统计假设，不称为独立收益确认。联合版两轮分别提高13.59%和10.04%，
因此继续验证其已冻结的58项共同实测池；原公式份额版不继续进行59项全测。

## 5．下一步的验收边界

三种名单按各自顺序报告1／5／20预算，资格及窗口完全一致。
完整Top-20在诊断前已冻结，但少数配置在最终批次前已经过诊断；后处理单列这部分，不能称为未见配置。
新增标定为零；模型开发的两次完整搜索、六项诊断及封装成本单列，不称总调优成本与原方法完全相同。
单启动、单图和短窗口的范围保持不变；不自动加帧、加图、重启或扩大全域并发标定。

未解释项仍包括CPU调用内调度／同步／缓存的分解，控制线程成本、阶段依赖与有限队列效应，
份额窗口近似、同构核心置换及历史DDR带宽误差。选点改善不等于这些因素已经准确建模。
