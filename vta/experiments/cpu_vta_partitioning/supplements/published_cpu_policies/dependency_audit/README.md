# YOLO并行完成依赖：离线核查

运行 `run_dependency_audit.py run` 完成来源核验、隔离提取、最小依赖回放、结果冻结、诊断分析和交付。可分别运行 `audit`、`extract`、`replay`、`analyze`、`validate`；`--output` 和 `--report-dir` 可改变本轮新产物位置。

没有板端命令、组件补测或推理。入口拒绝网络连接和外部进程，唯一允许的外部工具是Matplotlib本地字体发现。所有旧数据只读，原公式、DP和Top-20不变。

回放输入仅包含CPU0–2原等待隔离会话的worker整数纳秒工作量、可确认的同调用线程间隙和固定映射。先冻结输入及回放，再打开流水诊断参考。函数偏移序列完整匹配才分帧；无法分帧时只保留整段记录。线程非运行时间不等于精确调度等待，钟偏移一致性区间不是精确钟起点。

依赖图的任务时长为线程CPU时间；每次调用全部worker完成后才能执行下一次。它是理想单阶段工作回放，不模拟Linux共享调度、迁移、VTA或完整流水，不能输出完整FPS。已有阶段服务时间已包含完成依赖，不能将回放值再作为评分惩罚。

参考Daydream ATC2020第4节的任务／依赖表示及回放思想；本实现为独立TVM记录适配，不是其完整系统复现。源数据与新产物的哈希、boot及口径均保留。
