# 成熟资源规则与完整DP实验协议

## 固定条件

ResNet18、共同量化图、21单元、172个已编译模块、最多3个VTA岛；普通复制、固定Tile、队列2、空转0、poll/post-start均1000ns、CPU频率1,066,666kHz。配置显式冻结TVM_BIND_THREADS=1和TVM_EXCLUDE_WORKER0=1。标定输入0；性能输入16；完整输出资格输入0、16、17、18。

三种切图：CPU0–2/VTA3–17/CPU18–20，CPU0–2/VTA3–16/CPU17–20，CPU0–2/VTA3–19/CPU20。每种比较现有共享配置、阶段独立最快、固定核组分配、同分配逐线程固定、逐线程固定后重新分配、三核计算一核主机控制。

固定核组将CPU线程数设为组宽。CPU阶段可复用同组，同组set/run/get串行、异组并行。CPU actor就是worker0，不能额外加一个线程；VTA闲置线程池TID不计作多个活跃计算线程。

## 证据与组件复用

旧34签名逐条核验原程序、输入、运行库、固件、执行器字节、环境、原始计时、正确性和affinity凭据，保留原任务及boot ID并快照到新包。仅换控制器不重测。逐线程固定与专用主机属于新设置，不能改旧签名充当新实测。

每种新组件先通过4图资格检查，再预热5帧、计入32帧。记录set/run/get壁钟与隔离进程CPU核时。组件缓存可跨同条件启动复用，不作为性能独立样本。失效或不匹配项明确拒绝，不用同名文件替代。

同核数代价是一个模型假设：对三种切图的完整CPU阶段检查前缀／镜像核组，两种绑定模式均检查。差异超过5%时，只用规范连续分组域并补齐实际核组代价。假设产生的成本引用单列为core permutation推断，不标成所有mask都已实测。

## 绑核与执行控制

复用TVM -2逐线程模式，同时将caller固定至worker_core_map[0]。孤立组件首次按目标组创建池，避免池宽过大回退到共享组。固定模式要求threads等于map长度；组内迁移允许threads不超过mask大小。

资格探针记录逻辑slot→TID→实际单核mask，验证worker0和caller一致。正式性能不运行探针。小算子不要求所有配置线程都产生非零10ms粒度CPU tick。

新旧执行器在组内迁移下使用两个稳定配置作双向两轮桥接；差异超过5%时停止，不把二进制或初始化差异解释为绑核效果。桥接仅作诊断，不参与选点和独立样本计数。

主机和控制线程独立设置：共享时允许四核，专用时CPU计算只用0–2、VTA caller与producer/collector只用3。禁止通过全进程affinity重置已固定的计算线程。

## 选点与完整DP

流水计时前，按组件成本冻结六类策略选点与匹配干预，去重最多26项。初次探索与第二次独立核验分别保留两轮。按三个切图的几何平均吞吐改善比较，任何单切图明显退化单列；新增复杂策略相对简单固定组不足5%改善时选简单策略。

规则在第二次启动冻结，随后仅补全所选环境的完整阶段成本。完整DP保留位置、上一设备、VTA岛数、各核组累计服务、CPU／主机／边界工作和15个核心子集容量。VTA服务按单个物理加速器累计。边界各记一次。原前缀规则对照保留原目标；增强规则按固定设备组累计CPU服务。

逐线程固定时，CPU阶段的输入／输出核时归属于调用线程所在的第一个核心，计算核时归属于计算核组；两者分别进入核心子集容量，不能将边界工作分摊到整个计算核组。

Top20使用保留资源路径的精确label-setting，不套用Top1标量／Pareto剪枝。独立的拓扑与映射枚举核验全部Top20身份和分数。已有历史成本仅可作为离线算法测试fixture，不能生成本轮正式排名。

在同一冻结执行环境比较单线程物理映射、原前缀资源规则DP、增强DP。增强Top20和两个对照各前五名并集最多30项，排名在筛选前冻结。预算1、5、增强预算20分别冻结选点。确认数据不用于改成本、排名或再选点。

## 计时、启动和结果

正式窗口8帧预热、32完成时间戳、4尾帧，共31个保留完成间隔。资格对比8与24预热，差异超5%则全批用24并复核；仍不稳定则停止。每轮前后用单线程物理映射锚点，漂移超5%整轮作废，最多一次替换。失败和替换数据都保留。

六次正式内核启动依次为策略探索、独立核验与成本补齐、Top20筛选、独立确认、独立确认、独立确认。预检不计入；只允许用户手动重启。断线后根据原任务哈希回收，不能重复启动同一已接受任务。异常换启动时作废未完成的性能复本，保留来源明确且匹配的组件缓存。

流水核时取保留窗口首尾整体进程CPU时钟差除以31；不相加并发阶段进程CPU时间。正式性能无详细日志。

最终先平均同启动内两轮，再对最后三个启动配对报告差距与范围。综合改善至少5%、三个启动方向一致且无单切图超过5%退化，才支持本轮实际价值。机制结论使用对应匹配干预，不能把全部提升归于评分公式。不显著不等于等效；不报告正式显著性或等效性。

历史11.511FPS是不同浮点程序和输入下的短窗口记录，本轮历史切点使用当前整数边界共同图，单列差异，不设置必须超过历史数值的验收目标。
