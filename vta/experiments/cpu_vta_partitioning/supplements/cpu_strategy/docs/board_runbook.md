# 集中上板与恢复

所有命令由助手执行。用户仅按提示手动重启，不需输入SSH或实验命令。预检完成且当前无任务时才提示重启；数据同步后再次校验boot ID变化。

新批次为 `resnet18_resource_policy_dp_01`。预检不计正式启动；之后共六次。第二次可能有数百项缺失组件标定，是主要耗时来源；程序逐项缓存，断线后不重新测已接受项。

`status`显示已完成启动数、当前阶段和活动启动。`board resume --execute-board`只执行当前启动剩余任务，已经完成或预检使用的boot ID不会计作新复本。用户重启前先回收并sync；不自动执行reboot或分区操作。

SSH中断时保留本机与板端任务身份，恢复后等待原会话完成再回收。收齐文件、校验哈希并将凭据落盘后才清理板端大输出。超时、错误输出、错boot ID或错哈希均保留原始记录，不计作成功会话。

锚点漂移超5%时整轮最多替换一次；仍失败显示STOPPED_ANCHOR_DRIFT，不能不停重试。执行器桥接差异超5%显示STOPPED_EXECUTOR_DIFFERENCE，不能绕过继续选点。先排查，代码或运行程序变化时新建批次，旧证据保留。

重新启动发生在不完整复本中时，该性能复本移入abandoned并重做，已核验的同条件组件缓存可继续使用。最后三次确认不改选点。

分析输出 `analysis/REPORT_zh.txt`、组件曲线、策略对照CSV、Top20实测与排序图。INCOMPLETE不表示性能结论已经成立。
