# HANDOFF

`results.jsonl` binds every AXU5EVB export result to the frozen P4g artifact, stable candidate ID, complete ConfigEntity, compiler/schedule hashes, and a fresh TIR hash. Shared objects were deleted with their temporary directories; only size and SHA-256 remain. Passing P4i proves local cross-build/export deployability only. It does not prove current-boot loadability, board correctness, latency, or FPS.
