## 结果

选择每个几何一个已完成本地资格的历史池，排除重复 registry 和无效环境运行。
共12池、288个不同 candidate_id；149个原始 static-ok，30个 allocation_capacity
失败。规则拒绝15个，全部是原始 weight allocation 超限：Y07 10个、R50D 5个。
149个 static-ok 全部保留，另外15个容量失败未拒绝。

未拒绝的15个容量失败逐条核对错误末行后，13个是 local.acc_buffer，2个是
local.inp_buffer；本规则只检查 weight，所以这不是 weight 公式的已知反例，
但清楚说明它不能充当完整 SRAM 合法性门。

## 结论边界和下一步

- 比只在Y08开发池上匹配报错更强：同一公式在其他YOLO与ResNet50几何上也识别
  到权重超限，没有观察到误删已编译成功点。
- 不是新前瞻实验，不是新增288个上板结果，也不证明零误删泛化保证。
- 15/288=5.21%只是这些历史池中可预先拒绝的候选比例；不是墙钟减少5.21%，
  未测规则接入和完整搜索的实际开销。
- 其他10池没有拒绝点，因此不能把Y08或Y07高淘汰比例当通用收益。
- 后续应把相同生命周期分析扩展到ACC/input，验证时保留本次结果作为开发集，
  并在未使用过的候选资格任务中测量真实编译成本；不能替代完整lowering。
- 所有代码仍为离线开发审计，未改变已冻结的Y08搜索协议。
