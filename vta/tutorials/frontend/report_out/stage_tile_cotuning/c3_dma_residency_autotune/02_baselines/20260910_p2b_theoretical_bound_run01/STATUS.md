# C3 P2b 离线理论上限状态

状态：**完成离线分析；未使用 SSH/RPC，未上板，未产生新性能测量。**

冻结硬件参数对应 25.6 GMAC/s 理想峰值和每方向 1.6 GB/s optimistic AXI 有效载荷带宽。对冻结 10 类卷积，最乐观 full-duplex 模型均由 compute bound 主导；W03 最接近平衡，其 `Tcompute/Tdma=1.0064`。当前静态 DMA 相对不可约流量的放大倍数为 1.010–2.371，中位数 1.613。

一个重要结论是：在 perfect-overlap、满带宽的理想模型中，把当前静态 traffic 直接降到 unique traffic，10 类卷积的理论下界均不会继续下降，因为算力下界仍更大。这不表示 DMA 优化没有价值；它表示仅靠“总字节数”不能解释全部实测差距。真实系统中的请求启动、短突发、padding/stride、总线竞争、依赖与不完全重叠均未包含在这个理想模型中。

历史 80 点可关联 32 个正确候选：不可约下界效率中位数 75.45%，对应观测延迟中位差距 1.325×；最高有效算力 22.874 GMAC/s，即峰值利用率 89.35%。8 个匹配冻结静态 config 的候选峰值利用率中位数为 83.07%。历史 runtime traffic 诊断中 28 个 compute-bound、4 个 DMA-bound；4 个 DMA-bound 均是产生大量重载流量的非 incumbent 候选。这些都是历史板端证据的离线重用，不是本次实测。

因此，理论模型支持的后续问题不是笼统地“减少 DMA 字节就一定提高 FPS”，而是：避免调度把算子推入 DMA-bound 区域，并研究 bandwidth-only 模型未覆盖的请求粒度与启动/等待开销。该结论只针对单算子，不能直接等同整网 FPS。
