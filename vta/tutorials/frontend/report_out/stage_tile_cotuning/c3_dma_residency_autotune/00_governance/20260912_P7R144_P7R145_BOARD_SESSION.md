## u-dma-buf 布局边界

- P7R139：逐调用分配保持 output-data-weight 顺序，11/11 correctness 通过，但计时第 3 轮因
  非释放分配路径累计占用约 191.7 MiB 后无法再分配 692,224 B，实验失败关闭。
- P7R141：改成单组复用，但分配顺序变为 data-weight-output，仅 1/11 correctness 通过。
- P7R144：单组复用并恢复 output-data-weight 顺序，11/11 correctness 与 77 次计时全部通过，且无耗尽。

这组证据支持把“缓冲区大小、复用策略、分配顺序/地址布局”共同纳入运行时合同；由于三次运行不是
同一启动内随机化 A/B/A，暂不把底层原因直接归因于 u-dma-buf 驱动。

P7R143 是用户中断后留下的部分目录，只含前置合同/哈希，没有板端 observation、最终哈希或失败记录；
它不得用于任何结果统计，也没有被 P7R144 覆盖。
