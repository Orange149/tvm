# P7R462--P7R468：Y10 同空间在线选择归因结论

状态：`NODE_A_COMPLETE; LABELS_PREEXISTED_ATTRIBUTION_ONLY`

## 回答的问题

P7R460 的 64.84% 是不同候选空间、不同资格和测量粒度下的完整系统流程收益，不能全部归因于
搜索次序。本轮固定同一个 Y10 12 点 `tile×residence-mode` 池、同一个 budget=6、同一个完整
YOLOv3-tiny-320 构建器以及同一套三输入八输出正确性和七轮配对计时，只比较 DMA prior 与
mode-aware XGB 如何决定下一个候选。

## 结果

六次独立真实运行全部完成，两个策略各三个 seed，共 36 个候选派发，全部通过正确性门。

完整池 exact oracle 是
`dc939aafdfbb9e7e84172f7ce12b651551b75e95753ca7e33c30967750f7abb2`，paired ratio 为
`0.987878482`。DMA prior 的 exact time-to-quality 中位数相对 XGB 减少 46.43%，即提前
1.87 倍。两种策略第一次派发都已经进入 oracle+2%，所以本池只支持 exact-oracle 搜索次序收益，
不支持 +2% 首次命中优势。

协议强制两边都执行六个候选，因此完整墙钟几乎相同是合理结果。预算结束时的总成本不能用于声称
DMA prior 更省；若按达到 exact oracle 即停止，time-to-quality 才体现其优势。逻辑 DMA 是 VTA
runtime LOAD/STORE 语义量，不是物理 AXI burst。

## 主张边界

Y10 的完整池标签在 P7R461 协议冻结前已经存在。运行期间两个选择器均不读取旧标签，质量只在
结束后按不可变候选身份连接，但该事实不能消除实验设计者已知数据集的偏差。因此本轮可主张：

- 在相同候选空间、预算和完整图执行路径上，DMA 先验在 Y10 中更早找到 exact oracle；
- P7R460 的不同空间系统收益与本轮的搜索次序收益已经分开计量。

不能主张新的 prospective holdout、跨网络泛化、固定预算总成本下降、物理 AXI 流量或 COCO mAP。
