# YOLOv3-tiny Y00 输入复用与权重驻留双启动确认

日期：2026-09-23。状态：`TWO_BOOT_COMPLETE`。

## 结论

在 YOLOv3-tiny 的真实 Y00 卷积层（16→32、208×208、3×3、stride=1、padding=1）上，固定
Y00F06 h16/w52 Tile，对 original（O）、input-only（I）和 input＋首次使用全权重驻留（IW）进行
两个独立 boot 的板端对照。三个比较均达到预注册稳定改善门槛：每个 boot 的配对中位改善至少 2%，
且各 6/6 轮获胜。

| 基线→测试 | boot 1 | boot 2 | 判定 |
|---|---:|---:|---|
| O→I | 8.189%（6/6胜） | 8.266%（6/6胜） | 稳定改善 |
| I→IW | 2.281%（6/6胜） | 2.125%（6/6胜） | 稳定改善 |
| O→IW | 10.321%（6/6胜） | 10.175%（6/6胜） | 稳定改善 |

I→IW 是本轮最重要的增量比较：两者保持相同 Tile、输入请求、计算上下文、静态 arena 和一次函数结束
同步，只把 52 次、239,616 B 的权重请求改为首次使用时的一次 4,608 B 请求，逻辑权重请求量减少
98.077%。这支持“在已经采用输入复用的真实传输压力层上，权重驻留仍有独立净收益”。

## 编译与命令证据

| 指标 | O | I | IW |
|---|---:|---:|---:|
| INP 请求 B/calls | 1,588,736 / 104 | 794,368 / 52 | 794,368 / 52 |
| WGT 请求 B/calls | 239,616 / 104 | 239,616 / 52 | 4,608 / 1 |
| WGT arena | 2,304 B | 4,608 B | 4,608 B |
| ACC arena | 53,248 B | 106,496 B | 106,496 B |
| 累计 UOP LOAD | 208 B | 460 B | 460 B |
| 指令数 | 843 | 479 | 428 |
| 提交数 | 1 | 1 | 1 |

I 与 IW 的累计 UOP 装载量相同，因此该层没有出现 R18-H1 P4-S 的额外 UOP 代价。IW 的收益不能解释为
精确的 DMA 等待周期减少，但方向与权重请求和指令减少一致。

另一个固定 h4/w26、双虚拟线程的 Y00 memory-pressure 对照在第一个 boot 上得到 O2→PS 10.035%、
6/6轮获胜；该结果只有一个 boot，用于说明层与 Tile 的条件性，不升级为跨启动结论。

- boot 1：`ffdf1803-e65f-475e-963b-2d3f7273a816`；
- boot 2：`974d3891-8943-437c-b730-88179ea05d86`；
- 两个 boot 各 54 个正式计时样本，合计 108/108 正确；
- 每个候选使用三个 seed、统一预热、长期复用句柄、一次算子调用和相同 fresh-completion runtime；
- 耗时为预热后的板端算子调用耗时，不是纯硬件指令时间；
- 逻辑请求量不是外部总线物理流量，静态 arena 不是动态 SRAM 利用率；
- 这里只证明一个真实 YOLOv3-tiny 层和一个 Tile，不代表整网或全部卷积层。

## 下一步

这个结果证明了选择传输压力层的重要性，但整层权重只有 4,608 B，不能支撑“可调部分驻留”的贡献。
下一步回到 R18-H1 T8，仅做 P1/P2 的本地编译闭环，检验少保留权重是否能降低 P4-S 的 UOP/地址组织
代价，同时保持双虚拟线程、单提交、无逐组 drain。只有本地证据显示 UOP 或启动组织实际改善，才冻结
少量候选上板；否则保留全驻留结果，不为部分驻留强行增加复杂度。
