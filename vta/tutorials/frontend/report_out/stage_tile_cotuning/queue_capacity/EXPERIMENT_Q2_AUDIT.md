## 异常退出恢复边界

`fault_recovery_5e31f4a5_run1` 在 A 运行中发送 SIGTERM：终止前 16 帧正确且无残留进程，
但不重载 FPGA 就重启时 128/128 帧输出错误。这是失败样本，不得隐藏，也说明
FPGA manager 的 `operating` 状态不足以证明在途命令状态已经回滚。

冻结 runner/libvta 不变后，`fault_recovery_5e31f4a5_run2` 对 A/B/C/D 分别在完成
11/13/13/15 帧后 SIGTERM；终止前输出全部正确、进程均退出。每次重载哈希已核验的
`vta_hpc.bit` 后，同一 Linux boot 内各运行 128 帧，共 512/512 帧逐字节正确。
因此支持的恢复协议是 **fail-stop → 重新配置 FPGA → 重建 Executor/slot → 重新开始帧序列**；
不支持也不声称仅重新启动进程即可恢复。该测试不参与性能统计。
