# C2 增强：跨 Executor 输入池复用实现与资格化

日期：2026-09-08。沿用 `c3s_buffer_reuse` 产物目录以维持历史引用，
当前定位为第二项增强，不另拆第三创新点。原 DDR 争用研究仍是独立的探索支路，未恢复门控。

## 实现了什么

新增 `make_shared_buffer_plan.py`，将冻结静态审计转换为固定 K2 来源计划。
runner 新增可选 `--shared-buffer-plan PATH`；不传参数时继续原 external-K2。
普通安全 CPU→VTA 输入池兼作 slot0，只额外分配 slot1；其他边保留两个外部 slot。
未改变计算二进制、量化、tile、CPU 线程、K2、四态状态机、generation 或 bundle 交接。

启动过程：

1. 核对 CLI 实际指向的每 stage graph/lib/params，以及 `dladdr` 定位的已加载 TVM runtime/VTA driver 的 SHA-256。哈希错误在加载图之前拒绝。哈希子进程在启动线程池之前执行，不纳入稳态测量。
2. 重新读取实际 graph 的 entry/storage-id/所有输入使用，解码真实参数名字并拒绝参数池；运行时再次排除 linked parameter module。不是只相信计划的 eligible 字段。
3. 用 VTA 已有 `ndarray_shared_cpu_view` 取得真实映射地址。原 ext_dev `data` 是 DataBuffer 句柄，不能当作虚拟地址使用。
4. 验证实际 dtype/shape/连续性/offset、物理及虚拟256B对齐、已分配池内范围、跨候选冲突。所有 tensor 成功才借整条边；任何候选失败，在额外 slot 分配前整边回退并打印原因。
5. 借用 view 保留原 NDArray/pool owner；不对借用指针调用 VTAMemFree。管理器先于所属 Executor 销毁。运行期间不改变来源，不降低同步条件。

哈希范围是执行身份（计算文件和实际加载运行库）。离线 plan 中的本地 manifest 哈希用于审计追溯，
不要求板端含不同部署路径字段的 manifest 文本逐字相同。线程/affinity 本轮复用旧命令，
并非该内存计划接口新增的优化变量。更新了普通部署的 runner cache key，使新增头文件变化也会失效缓存。

这不是 USMP 的算法复现或调用：没有重新规划算子内部工作区/池内偏移；复用已有存储信息，
补上独立 GraphExecutor 与多帧交接 slot 之间的绑定及生命周期规则。
生命周期复用思想不作为新原理，generation 等既有 C2 协议不重复计作新贡献。

## 已通过的资格化

同 boot `a5220e22-f562-40be-bbe9-058b6fbeed50`，CPU1066666kHz、原bitstream，
每种模式独立进程，2帧warmup、32正式帧。8个输入（零、uniform、normal及5个独立固定seed normal）
循环交替，不是32个独立输入，也不是 ImageNet 精度测试。

- 四拓扑 external/anchor 共256正式帧，anchor的128帧最终输出与external逐字节相同。
- A 错误entry计划整边回退，额外32帧输出同样逐字节相同，分配恢复为external基线。
- A 错误graph哈希在 `[LOAD]` 之前拒绝，无VTA执行。
- 成功运行共288正式帧；实际做160帧、640000B输出对照，不以FNV哈希代替本次字节比较。
- 每个复用边在anchor模式观察到15次 slot0 producer run 与 slot1 consumer run 时间重叠，5条复用边合计75次；说明并非只测串行绑定。
- 各成功运行从warmup后至结束高水位增长为0；现有管理器结束时验证全部slot FREE。
- 原生规则测试23项（输入/参数/别名/entry/输出别名/no-op、物理对齐/越界/溢出、SHA、参数格式等）通过；静态规则10项通过。
- 原33项编译/共享边界/E3等回归测试另行运行，不把它们当作本次新增的23项。

## 尚未完成

1000帧/拓扑自然交错压力单独归档，不混为本节32帧结果。
强制慢消费者、完整异常退出/整bundle部分不合格的板端负例，以及三独立boot ABBA性能保护尚未全部完成。
既有局部数值反例的精确输入并未直接用于这些整网输入；当前证明保持冻结流水线的原数值行为，
不声称修复独立量化差异或通过整网精度资格化。
本实验开启输出dump/分配诊断，只支持分配与正确性结果，不报告其FPS为无损性能证据。
